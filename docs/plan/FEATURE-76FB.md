## Objective

Replace the application icon with the new set in `C:\Dev\EnigmaLibs\Branding\Apps\final3\backup` everywhere
the app shows it: the executable, the window and taskbar, the About dialog, the `app.ico` beside the
executable (and so the MSI's shortcuts and *Apps & features* entry), and the Linux installer's launcher
icons.

## Context & constraints

- **The new artwork** is the same BK-B2 drawing ("Zipped page", *Soft* palette, no tile) **scaled to fill
  the frame**: the `final2` drawing ×1.3333, its longest side spanning 16 to 240 of the 256-unit view box.
  Frames 40 px and up come from `enigma-backup.svg`, 16–32 px from `enigma-backup-small.svg`. Generated by
  `Branding/Apps/export.py final3`, which the SVGs' header comments name.
- **The new `.ico`** (11,382 bytes) holds ten 32-bit RGBA PNG frames (16, 20, 24, 32, 40, 48, 64, 96, 128,
  256), the same sizes as today's. Each frame is byte for byte the matching `png/enigma-backup-N.png`
  (checked while planning).
- **Where the icon lives** (FEATURE-9755, FEATURE-5D75, FEATURE-61C4, FEATURE-F207); today each file is
  byte for byte the `final2` set (checked while planning):
  - `src/Enigma.Backup.Desktop/Assets/enigma-backup.ico`: the `ApplicationIcon`, the `Icon` of
    `MainWindow` and `StartupErrorWindow`, and the `app.ico` the csproj copies beside the executable. The
    zips ship that copy, and `buildmsi.ps1` hands it to the MSI as the product and shortcut icon;
  - `src/Enigma.Backup.Desktop/Assets/enigma-backup.png`: the About dialog's image, the `.ico`'s 256
    frame;
  - `packaging/linux/icons/enigma-backup-{16,24,32,48,64,96,128,256}.png`: what `install.sh` installs
    (`ICON_SIZES`).
- The names stay the same, so no reference changes.
- `AppIconTests` (Desktop tests) checks the `app.ico` copy against the asset.
- `CLAUDE.md` *Environment notes* names `Branding/Apps/final2/backup` as the source of the icon.
- The source directory is outside the repository and is left in place.

## Steps

1. Copy, byte for byte:
   - `enigma-backup.ico` → `src/Enigma.Backup.Desktop/Assets/enigma-backup.ico`;
   - `png/enigma-backup-256.png` → `src/Enigma.Backup.Desktop/Assets/enigma-backup.png`;
   - the 16, 24, 32, 48, 64, 96, 128 and 256 PNGs → `packaging/linux/icons/`.
2. `CLAUDE.md`: the icon now comes from `Branding/Apps/final3/backup`.
3. Release build, then the whole suite. Check the frames by script.
4. Launch the Release build and look at the window icon and the About image.

## Acceptance criteria

- The three destinations hold the new files byte for byte (`cmp`), and no `final2` file is left.
- A script check shows ten 32-bit RGBA PNG frames (16 to 256) in the asset `.ico`. `enigma-backup.png`
  is its 256 frame byte for byte. Each Linux PNG is the `.ico` frame of its size byte for byte.
- The Release build has zero warnings, and the whole suite has no failure the run's baseline did not
  have. `AppIconTests` passes against the new asset.
